# GA4 analytics integration — 22 September 2026

User supplied web-stream ID `G-1MNPG57MNM` and confirmed Enhanced measurement was turned off.
This integration measures production pathname navigation plus browser-observed trip creation, import
submission/retry, place addition/confirmation, generation/regeneration, edits, sharing and action failures.
It uses the same typed API client as the UI so successful events follow successful responses; dry-run
edits and polling do not count as product actions. Server/worker webhook events are not represented as
GA4 completion events without a corresponding browser observation.

Trip/place IDs, share tokens, query strings, free-text form fields and response contents are omitted from
explicit GA4 payloads. Route templates aggregate pages. Local development is excluded, while opt-in debug
traffic is labeled. No Vercel Web Analytics dependency remains. Google Analytics uses cookies and device
information; the privacy page was updated. CSP allows the tag and its analytics destinations.
