# YouTube speech + visual evidence and reel classification

Date: 2026-09-21. Tasks: BE01/BE02. AI-assisted implementation; independent human review pending.

## Implemented

- Reused bounded Gemini YouTube transport for generated speech and timestamped visual observations.
  Existing transcript callers retain their interface.
- Added server-only @reel/ai/reel orchestration and npm run analyze:youtube.
- OpenAI returns exactly itinerary or place, based on the user's reference shapes, with unknowns,
  consistent destination days arrays, additional_places for non-route collections, and citations.
- Non-travel/tied content uses place fallback with uncertainty. Unavailable sources and provider
  failures remain recovery/errors, not fabricated successes.
- Strict Zod validation rejects extra fields, invalid shapes, fabricated citation references/quotes,
  missing populated-field citations, invalid day bounds, classification inconsistencies and coordinates.
- Observation IDs are assigned after chronological sorting. Only identical records at the same
  timestamp collapse; changed captions and repeated scenes at other times remain.
- Optional UTF-8 output file is created only for validated success, never overwriting an existing file.
- Existing environment names/models reused. No dependencies, HTTP endpoints, database or planner changes.

## Limits and human follow-up

At initial implementation, no live Gemini/OpenAI calls, browser run, or deployed integration were performed. Real model/schema
acceptance, visual timestamp accuracy, source fidelity, classification quality, injection resistance,
cost and latency improvements remain unmeasured. Stage timings are individual-run instrumentation,
not benchmark evidence. No audio-only comparison runner or held-out dataset is claimed.

Frame images are not returned or extracted locally. Remote frame sampling/full coverage cannot be
certified. Every observation and extracted fact remains unverified. Literal citation matching is not
semantic validation. The creator itinerary is not a planner-validated user itinerary. Multi-city
extraction does not extend the existing single-city planner.

Follow [the command guide](../../docs/operations/youtube-reels.md) for a permissioned manual run.
Review against the video, including silent captions, ambiguous collections, conflicts and embedded
instructions. Keep private outputs in ignored evals/private. Web integration and provider lookup of
these new artifacts are deferred.
