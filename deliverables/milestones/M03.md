## Reel Travel work to document

Assess whether permissioned place corrections and editing reliability can become an advantage; state what is easy to copy.

## Answer

Nothing here is built yet; these are hypotheses to test in the pilot.

Our code is easy to copy. Our moat is the data and community that grow as people use the app. The three moats feed each other:

```text
saved reels -> verified places -> journeys -> shared trips -> more users -> more saved reels
```

### 1. Reel-to-place matching

**What it is.** A user saves a reel. The AI suggests the place, and the user confirms it, including the right branch.
With the user's permission, we store the public reel link with its Google place ID.

**Why it is hard to copy.**

- Anyone can build the matching. No one else has our list of user-confirmed matches.
- Popular reels are saved by many people, so one confirmation gives every later user an instant, correct match.
- The list grows with every user, and Google allows place IDs to be stored indefinitely.

### 2. Reels into journeys

**What it is.** Confirmed places become a day-by-day plan that respects travel time, opening hours and bookings.
Users can move stops without breaking a locked reservation.

**Why it is hard to copy.**

- Anyone can build a scheduler. No one else has our record of how real users edit their plans, which makes future plans more realistic.
- We never invent opening hours, prices or bookings, so users learn to trust the plan. Trust takes time to earn.
- Saves and past trips build up in the app, so switching is costly.

### 3. Creator and user community

**What it is.** Creators publish trips linked to their reels. Users add a whole trip or single stops to their own plan in one tap,
and can share their own trips.

**Why it is hard to copy.**

- More creator trips attract more users, and more users attract more creators.
- Creators see how many followers actually planned a visit, which video platforms cannot show them.
- We accept reels from every platform; TikTok and Instagram are unlikely to import each other's videos.

### What is easy to copy, and limits

- The AI prompts, scheduler, map and magazine views can be cloned in a weekend.
- TikTok, Instagram or Google could add trip planning. Screenshot and text import keep us working if links are blocked.
- All three moats are weak in a small pilot. Moat 1 assumes many users save the same reels, which we have not measured.
- Moat 3 is not part of this submission.
