# M18: Landing page

Owner: Member 1. Status: standalone implementation and local checks complete; GitHub publication and platform-preview evidence pending.

Reel Travel's [root landing page](../../index.html) explains why saved inspiration needs a path to an actual trip. Its hero has a clear “Plan my trip” CTA, followed by how-it-works, product features, transparent pricing, FAQ and a final CTA. The sample itinerary is interactive and explicitly illustrative. The free beta is available now; paid prices are proposals, not sale offers.

The page uses semantic HTML, a unique title and description, canonical URL, index/follow meta directive, structured WebSite data and a sitemap. Static Open Graph and Twitter/X tags point to a local 1200 × 630 social image. CSS/JavaScript/assets live under `apps/web/src/landingPage`; GitHub Pages can serve the root HTML without a Next.js server.

[Implementation, screenshots and local verification](../evidence/landing-page-2026-09-23.md). [Publishing instructions](../../apps/web/src/landingPage/README.md). Expected URL after publication: https://namprice227.github.io/reel-travel/.

Local browser checks cover five screen widths, keyboard controls, mobile navigation, sample-day changes, static asset loading and no-JavaScript fallback. Automated accessibility scans reported zero violations in the tested views. Live social-card rendering and search indexing are not yet claimed.
