# Team planning

Use tasks.csv as the task-status source of truth: todo, in_progress, blocked, review, done.
Dependencies identify integration handoffs; fixtures allow earlier independent UI/module work.

Roadmap gates are team dates. M00–M20 identify course answers. Do not confuse a gate with a course phase.
A done task has satisfied its acceptance condition, passed appropriate checks, received peer review,
and linked evidence. Scaffold creation does not complete any product task.

Use team.md for role allocation, roadmap.md for dates, decisions.md for unresolved choices,
and contributions.csv for actual work. Keep original task IDs when adjusting ownership or estimates.
