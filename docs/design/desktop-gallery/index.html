How to use these concepts

Start by comparing the three home pages and three itinerary screens. Pick a visual direction, then use the complete Editorial Blue set to review screen coverage. Components can be adapted to the chosen palette and layout.

  • All venue names, dates, bookings, maps and photos are illustrative. Decorative destination imagery is not source evidence.
  • Review the frontend plan for exact behavior, data boundaries and acceptance checks. Raster designs may abbreviate fields or controls; the written requirements govern implementation.
  • Other directions currently cover home, My trips, itinerary and magazine. Their remaining screens can inherit the complete flow from direction A.
  • Each concept has its exact built-in imagegen prompt in prompts.json. See the gallery record for review notes and generation provenance.
